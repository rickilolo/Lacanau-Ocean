# Site Lacanau Océan

## Mise en ligne
1. Envoyer `index.html` et le dossier `images/` à la racine du dépôt GitHub.
2. Dans `index.html`, remplacer `VOTRE-EMAIL@EXEMPLE.FR`.
3. Le lien `guide.html` est prévu pour le futur livret d'accueil.
4. Les photos avec filigrane immobilier sont provisoires : les remplacer par vos propres photos avant la version définitive.

GitHub Pages : Settings > Pages > Deploy from a branch > main / root.
